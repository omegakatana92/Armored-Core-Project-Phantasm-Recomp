# Armored Core: Project Phantasma PSX Recomp

Static recompilation project for **Armored Core: Project Phantasma (USA)** on the original PlayStation.

This project uses **PSXRecomp** to statically recompile the PlayStation executable for modern systems and integrates the current **recomp-ui** launcher workflow.

## Quick start for developers

Clone the repository and initialize its submodules:

```bash
git clone --recursive https://github.com/omegakatana92/Armored-Core-Project-Phantasm-Recomp.git
cd Armored-Core-Project-Phantasm-Recomp
git submodule update --init --recursive
```

Use your own legal copy of the USA release of **Armored Core: Project Phantasma** when running the generation workflow.

A typical current-layout generation/build flow is:

```bash
python3 psxrecomp/psxrecomp_cli.py generate \
  --config game.toml \
  --project-root . \
  --disc /path/to/Armored-Core-Project-Phantasma-USA.cue

cmake -S . -B build-release -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build-release --target psx-runtime
```

Exact commands can change as PSXRecomp develops, so consult the documentation included in the pinned `psxrecomp` submodule when necessary.

## recomp-ui

The project is intended to use the current **recomp-ui** launcher and setup workflow. The launcher can provide a more user-friendly way to select and validate a legally obtained game copy, configure settings, and launch the recompiled title.

UI presence alone should not be considered proof that the game is fully playable. Runtime status should only be updated after the relevant features have actually been tested.

## Status definitions

- **Buildable** — recompilation generates and compiles successfully.
- **UI Functional** — recomp-ui launches and its required setup/settings flow works.
- **Bootable** — the recompiled game reaches startup or the title screen.
- **Playable** — actual gameplay can be reached and controlled.
- **Complete** — substantial full-game testing has been performed without known game-breaking recompilation problems.

These labels should be used conservatively. A successful build alone does not mean the game is complete or even playable.
